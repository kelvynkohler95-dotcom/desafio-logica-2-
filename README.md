# 🛡️ Classificador de Nível de Herói

## 📝 Descrição do Desafio
Este projeto foi desenvolvido como parte da **Formação Lógica de Programação da DIO (Digital Innovation One)**. O objetivo é aplicar conceitos fundamentais de programação para classificar um herói com base em sua quantidade de Experiência (XP).

---

## 🚀 Tecnologias Utilizadas
* **JavaScript**: Linguagem principal para a lógica do desafio.
* **Node.js**: Ambiente de execução para rodar o script no terminal.
* **Git & GitHub**: Para versionamento e hospedagem do código.

---

## 🧠 Conceitos Aplicados
Para a construção deste projeto, utilizei:
* **Variáveis**: Para armazenar dados dos heróis.
* **Arrays e Objetos**: Para organizar a lista de personagens de forma eficiente.
* **Operadores**: Para comparações de valores.
* **Laços de Repetição (`for`)**: Para percorrer e processar múltiplos heróis automaticamente.
* **Estruturas de Decisão (`if/else if`)**: Para determinar o nível do herói com base nas regras de XP.

---

## 📊 Tabela de Níveis
| XP | Nível |
| :--- | :--- |
| Menor que 1.000 | Ferro |
| Entre 1.001 e 2.000 | Bronze |
| Entre 2.001 e 5.000 | Prata |
| Entre 5.001 e 7.000 | Ouro |
| Entre 7.001 e 8.000 | Platina |
| Entre 8.001 e 9.000 | Ascendente |
| Entre 9.001 e 10.000 | Imortal |
| Maior ou igual a 10.001 | Radiante |
